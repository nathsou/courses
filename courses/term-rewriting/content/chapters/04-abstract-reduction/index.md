The questions raised by the reduction graphs of the last chapter (does rewriting stop? is the answer unique?) make sense for any relation, not just for rewriting on terms. Asking them in that generality strips away everything irrelevant, and the proofs become short pictures. This chapter works with an arbitrary set and an arbitrary relation on it; Parts IV and V then return to terms with these results in hand.

## Abstract reduction systems

:::definition[Abstract reduction system]
An **abstract reduction system** (ARS) is a set $A$ with a binary relation $\to$ on it. We use the notation of Chapter 3: $\to^*$, $\to^+$, $\leftrightarrow^*$, normal forms. Two elements $b$ and $c$ are **joinable**, written $b \downarrow c$, if $b \to^* d$ and $c \to^* d$ for some $d$.
:::

:::definition[The properties]
An ARS is

- **terminating** (or *strongly normalising*) if there is no infinite chain $a_0 \to a_1 \to a_2 \to \cdots$;
- **weakly normalising** if every element has at least one normal form;
- **confluent** if whenever $b \leftarrow^* a \to^* c$, then $b \downarrow c$;
- **locally confluent** if whenever $b \leftarrow a \to c$ (single steps), then $b \downarrow c$;
- **Church–Rosser** if $b \leftrightarrow^* c$ implies $b \downarrow c$;
- **convergent** (or *complete*) if it is terminating and confluent.
:::

A configuration $b \leftarrow^* a \to^* c$ is called a **peak** (or a fork) and the joining reductions a **valley**. Confluence says every peak has a valley; local confluence only asks it for peaks of single steps, which is much easier to check because there are fewer of them. For a term rewriting system, Chapter 16 shows that local confluence can be checked by looking at finitely many special peaks.

Draw some systems and see which properties hold. The examples include the ones that matter in this chapter.

## Church–Rosser and confluence

These two properties look different: Church–Rosser talks about conversion, where steps may go both ways, while confluence only talks about peaks. They are equivalent.

:::theorem{name="Church and Rosser" year=1936 status=proved}
An ARS is Church–Rosser if and only if it is confluent.
:::

:::proof
A peak $b \leftarrow^* a \to^* c$ is in particular a conversion $b \leftrightarrow^* c$, so Church–Rosser implies confluence.

Conversely, suppose the system is confluent and $b \leftrightarrow^* c$. Induction on the number $n$ of steps in the conversion. If $n = 0$, $b = c$. Otherwise $b \leftrightarrow^* c' \leftrightarrow c$ with $n - 1$ steps from $b$ to $c'$, so by induction $b \to^* d \leftarrow^* c'$ for some $d$.

- If the last step is $c' \leftarrow c$, then $c \to c' \to^* d$ and $b \to^* d$: joinable.
- If it is $c' \to c$, then $d \leftarrow^* c' \to c$ is a peak, and confluence gives $e$ with $d \to^* e \leftarrow^* c$. Then $b \to^* d \to^* e$ and $c \to^* e$. $\blacksquare$
:::

The name comes from Alonzo Church and J. Barkley Rosser, who proved in 1936 that the λ-calculus has this property.:cite[church-rosser1936] Their result is why a program in a functional language has at most one result whichever order its expressions are evaluated in, and Chapter 28 returns to it.

## Convergent systems decide equivalence

Here is the payoff that drives the whole subject.

:::theorem{status=proved}
In a confluent system, every element has at most one normal form. In a convergent system every element $a$ has exactly one, written $a{\downarrow}$, and
$$ b \leftrightarrow^* c \iff b{\downarrow} = c{\downarrow}. $$
:::

:::proof
If $a \to^* n_1$ and $a \to^* n_2$ with both normal forms, confluence gives $d$ with $n_1 \to^* d$ and $n_2 \to^* d$; normal forms have no successors, so $n_1 = d = n_2$. With termination, rewriting from $a$ must stop, and where it stops is a normal form, so one exists.

If $b{\downarrow} = c{\downarrow}$ then $b \to^* b{\downarrow} = c{\downarrow} \leftarrow^* c$, a conversion. Conversely if $b \leftrightarrow^* c$ then, as $b \leftrightarrow^* b{\downarrow}$ and $c \leftrightarrow^* c{\downarrow}$, we have $b{\downarrow} \leftrightarrow^* c{\downarrow}$; Church–Rosser makes them joinable, and since they are normal forms they are equal.
:::

Read this with Chapter 0's group rules in mind. The equivalence $\leftrightarrow^*$ generated by a set of equations is "provably equal" (Chapter 18 makes this precise). If the equations can be oriented into a convergent system, then provable equality is **decidable**: rewrite both sides to normal form and compare. That is exactly what the query `? I(a * I(b)) == b * I(a)` did. Finding such a system is the job of Knuth–Bendix completion (Chapter 19).

## Newman’s lemma

Confluence quantifies over arbitrarily long reductions, so it is hard to check directly. Local confluence is much easier. Does it suffice? Not in general: the first example in the lab above, Newman's counterexample, is locally confluent but not confluent ($b \to a$ and $b \to c \to d$ reach two different normal forms), because the loop $b \to c \to b$ lets the peak at $b$ be "joined" only by going back up. Termination rules that out.

:::theorem{name="Newman’s lemma" who="M. H. A. Newman" year=1942 status=proved}
A terminating, locally confluent ARS is confluent.
:::

The proof uses **well-founded induction**, the principle behind every termination argument in the course. If $\to$ is terminating, then to prove that a property $P(a)$ holds for every $a$, it suffices to prove $P(a)$ assuming $P(b)$ for every $b$ with $a \to^+ b$. (If $P$ failed somewhere, pick a failing $a_0$; some successor $a_1$ must fail too, then some successor of $a_1$, and so on: an infinite chain, which termination forbids. Appendix A gives the details.)

::::zoom{levels="Idea, Proof"}
:::level[Idea]
Take a peak $b \leftarrow^* a \to^* c$ and split off the first steps: $b \leftarrow^* b_1 \leftarrow a \to c_1 \to^* c$. Local confluence joins $b_1$ and $c_1$ at some $d$. Now the peaks at $b_1$ and at $c_1$ start strictly below $a$, so by induction they can be joined. Glue the three valleys together.
:::
:::level[Proof]
We prove by well-founded induction on $\to$ that every $a$ has the property "every peak $b \leftarrow^* a \to^* c$ is joinable". Take such a peak. If either reduction has length 0, say $a = b$, then $b = a \to^* c$ and the peak is trivially joinable. Otherwise write
$$ b \leftarrow^* b_1 \leftarrow a \to c_1 \to^* c. $$
By local confluence there is $d$ with $b_1 \to^* d$ and $c_1 \to^* d$. Since $a \to b_1$, the induction hypothesis applies to $b_1$ and the peak $b \leftarrow^* b_1 \to^* d$: there is $e$ with $b \to^* e$ and $d \to^* e$. Since $a \to c_1$, it also applies to $c_1$ and the peak $e \leftarrow^* d \leftarrow^* c_1 \to^* c$ (note $c_1 \to^* d \to^* e$): there is $f$ with $e \to^* f$ and $c \to^* f$. Then $b \to^* e \to^* f$ and $c \to^* f$, so $b \downarrow c$. $\blacksquare$
:::
::::

Newman proved it in 1942, in a paper about "theories with a combinatorial definition of equivalence";:cite[newman1942] the short proof above is due to Gérard Huet, who made it the starting point of his 1980 study of confluent reductions.:cite[huet1980] For terminating rewrite systems it reduces confluence to local confluence, and Chapter 16 reduces local confluence to finitely many critical pairs, so for terminating systems confluence becomes decidable.

```quiz
q: 'Which system is locally confluent but not confluent?'
options:
  - text: '`a -> b, b -> a, a -> c, b -> d`'
    correct: true
    why: 'Each one-step peak at `a` or `b` can be joined by stepping back (a → b → d, b → a → c), but c and d are distinct normal forms reachable from a. The loop between a and b is what defeats Newman’s lemma.'
  - text: '`a -> b, a -> c, b -> d, c -> d`'
    why: 'This diamond is confluent (and terminating).'
  - text: '`a -> b, a -> c`'
    why: 'Not even locally confluent: b and c are distinct normal forms one step from a.'
  - text: '`a -> a`'
    why: 'Confluent: every peak is a → a, trivially joinable. (It is not terminating.)'
```

## Finite systems in code

For a finite ARS every property in this chapter is decidable by graph search, which is how the lab above works. Write the basic piece.

```code
id: abstract-reduction/normal-forms
title: The normal forms of an element
prompt: |
  A finite ARS has nodes `0 … n-1` and a list of edges `[from, to]`. Write `normalFormsOf(n, edges, x)`: the normal forms reachable from `x` in zero or more steps, sorted increasingly. Make sure it terminates on systems with cycles.
starter: |
  export function normalFormsOf(n: number, edges: [number, number][], x: number): number[] {
    return [x];
  }
tests: |
  import { test, expect } from 'test';
  import { normalFormsOf } from 'solution';

  test('a diamond has one normal form', () => {
    expect(normalFormsOf(4, [[0, 1], [0, 2], [1, 3], [2, 3]], 0)).toEqual([3]);
  });
  test('two normal forms', () => {
    expect(normalFormsOf(3, [[0, 1], [0, 2]], 0)).toEqual([1, 2]);
  });
  test('a normal form is its own normal form', () => {
    expect(normalFormsOf(3, [[0, 1], [0, 2]], 2)).toEqual([2]);
  });
  test("Newman's counterexample: cycles are fine", () => {
    // b=0 -> a=1, b -> c=2, c -> b, c -> d=3
    expect(normalFormsOf(4, [[0, 1], [0, 2], [2, 0], [2, 3]], 0)).toEqual([1, 3]);
  });
  test('an element on a loop with no exit has no normal form', () => {
    expect(normalFormsOf(2, [[0, 1], [1, 0]], 0)).toEqual([]);
  });
solution: |
  export function normalFormsOf(n: number, edges: [number, number][], x: number): number[] {
    const succ: number[][] = Array.from({ length: n }, () => []);
    for (const [a, b] of edges) succ[a].push(b);
    const seen = new Set([x]);
    const stack = [x];
    while (stack.length) {
      const u = stack.pop()!;
      for (const w of succ[u]) if (!seen.has(w)) { seen.add(w); stack.push(w); }
    }
    return [...seen].filter((u) => succ[u].length === 0).sort((a, b) => a - b);
  }
hints:
  - 'First compute everything reachable from `x` with a depth-first search and a `seen` set (that is what makes cycles harmless).'
  - 'Then keep the reachable nodes with no outgoing edge.'
```

:::key
- Termination: no infinite chains. Confluence: every peak has a valley. Convergent: both.
- Church–Rosser (conversions are joinable) is equivalent to confluence.
- In a convergent system every element has a unique normal form, and $b \leftrightarrow^* c$ exactly when the normal forms agree: equality becomes decidable.
- Newman's lemma: terminating + locally confluent ⇒ confluent. Without termination it fails.
:::

:::exercises
1. Show that a confluent system has the unique-normal-form property, and give a system with unique normal forms that is not confluent. (Hint: an element with no normal form.)
2. **Semi-confluence** asks that $b \leftarrow a \to^* c$ be joinable. Prove that semi-confluence is equivalent to confluence.
3. The **strong confluence** property says $b \leftarrow a \to c$ implies $b \to^{=} d \leftarrow^* c$ (where $\to^=$ is zero or one step). Prove that strong confluence implies confluence, without assuming termination.
4. Prove that a weakly normalising, locally confluent system need not be confluent, and that a terminating system with unique normal forms is confluent.
:::
