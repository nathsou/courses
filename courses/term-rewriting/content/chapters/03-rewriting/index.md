We now have terms, positions and matching. Put them together and we get the object of study: the rewrite relation of a set of rules.

## Rules and the rewrite relation

:::definition[Rewrite rule, term rewriting system]
A **rewrite rule** is a pair of terms $l \to r$ such that $l$ is not a variable and every variable of $r$ occurs in $l$. A **term rewriting system** (TRS) $R$ is a set of rules.
:::

Both conditions are there to make rewriting sensible. If $l$ were a variable $x$, the rule would apply to every term whatsoever. If $r$ had a variable $y$ that is not in $l$, a match would not say what to put for $y$, so a step could produce anything: `F(x) -> G(x, y)` would rewrite `F(A)` to `G(A, A)`, `G(A, F(A))`, `G(A, G(A, A))` and so on, without end. The workbench reports both mistakes as errors.

:::definition[One rewrite step]
$s \to_R t$ (read "$s$ rewrites to $t$") if there are a rule $l \to r \in R$, a position $p \in \mathrm{Pos}(s)$ and a substitution $\sigma$ with
$$s|_p = l\sigma \quad\text{and}\quad t = s[r\sigma]_p.$$
The subterm $s|_p = l\sigma$ is a **redex** (for *reducible expression*) and $r\sigma$ is its **contractum**.
:::

In words: find a subterm that is an instance of a left-hand side, and replace it by the same instance of the right-hand side. With the Peano rules, `S(0) + S(0)` has one redex, at the root, and `S(0) + S(0)` $\to$ `S(0 + S(0))` $\to$ `S(S(0))`.

We write $\to^*$ for zero or more steps (the reflexive transitive closure), $\to^+$ for one or more, and $\leftrightarrow^*$ for the equivalence generated by $\to$, where steps may be taken in either direction. A term with no redex is a **normal form**; if $s \to^* t$ and $t$ is a normal form, $t$ is *a* normal form of $s$. (We cannot yet say *the* normal form: a term may have none, or several.)

## Closure under substitution and context

Two properties of $\to_R$ are used so often that they deserve a name and a proof.

:::proposition{status=proved}
If $s \to_R t$, then for every substitution $\tau$ and every term $u$ with a position $q$:

1. $s\tau \to_R t\tau$ (closure under substitution), and
2. $u[s]_q \to_R u[t]_q$ (closure under contexts).

Moreover $\to_R$ is the *smallest* relation that contains every instance of every rule and has these two properties.
:::

:::proof
Let $s|_p = l\sigma$ and $t = s[r\sigma]_p$.

(1) Applying $\tau$ commutes with taking subterms and replacing: $(s\tau)|_p = (s|_p)\tau = l(\sigma\tau)$ and $t\tau = (s\tau)[r(\sigma\tau)]_p$, so the same rule applies at the same position with the substitution $\sigma\tau$.

(2) $(u[s]_q)|_{q.p} = s|_p = l\sigma$ and $u[t]_q = (u[s]_q)[r\sigma]_{q.p}$, so the rule applies at position $q.p$.

For minimality: any relation containing all rule instances $l\sigma \to r\sigma$ and closed under contexts contains $s[l\sigma]_p \to s[r\sigma]_p$ for every $s$ and $p$, which is every step of $\to_R$.
:::

This is the precise sense in which rewriting "replaces equals by equals": wherever a part of a term matches a rule, whatever surrounds it and whatever its variables stand for.

## The reduction graph

All the ways to rewrite a term form a graph: its nodes are the terms reachable from it, and there is an arrow for each single step. Arrows are labelled with the position of the redex.

::reduction-graph{rules="#infixl 6 +\n0 + y -> y\nS(x) + y -> S(x + y)" term="(0 + 0) + (0 + 0)"}

Edit the term to `(S(0) + 0) + (0 + S(0))`, or add the rule `x + 0 -> x` and watch new arrows appear (some of them lead to the same place by a different route). Then try a system where things go wrong:

::reduction-graph{rules="F(x) -> G(x, x)\nA -> B\nG(A, B) -> C" term="F(A)" title="Two normal forms"}

`F(A)` has two normal forms here, `C` and `G(B, B)`: the order of steps decides the answer. And here is a term with no normal form at all, but which reaches one if you are careful:

::reduction-graph{rules="F(x, B) -> B\nA -> A\nC -> B" term="F(A, C)" title="Choose well, or loop"}

`A -> A` lets you rewrite for ever without making progress; the step `C -> B` followed by the first rule reaches `B` in two steps. These three pictures are the three questions of the rest of the course: how to choose steps (Chapter 5), whether rewriting stops (Part IV), and whether the answer is unique (Part V).

## Rewriting in your engine

Two operations cover what the rest of the course needs from a single step:

- `rootRewrite(rules, t)`: try the rules in order at the root of `t` only, and return the contractum of the first that matches, or `null`;
- `allReducts(rules, t)`: every term reachable from `t` in exactly one step.

Both are built from the functions you wrote in the previous two chapters. In this exercise you import them from `engine`: if you passed those exercises, the code that runs is yours. (If you skipped them, the reference implementations stand in. The [Your engine](/engine/) page shows which is which.)

```code

title: One rewrite step
provides: [rootRewrite, allReducts]
prompt: |
  A rule is an object `{ lhs, rhs }`. Implement

  - `rootRewrite(rules, t)`: the first rule (in order) whose left-hand side matches `t` **at the root** determines the result $r\sigma$; return `null` if none matches;
  - `allReducts(rules, t)`: all one-step reducts of `t`, ordered by position in pre-order and, at each position, by rule order. Keep duplicates (two different steps can lead to the same term).
starter: |

  import { match, apply, positions, at, replaceAt } from 'engine';

  export function rootRewrite(rules: readonly Rule[], t: Term): Term | null {
    return null;
  }

  export function allReducts(rules: readonly Rule[], t: Term): Term[] {
    return [];
  }
tests: |
  import { test, expect } from 'test';
  import { rootRewrite, allReducts } from 'solution';
  import { rules, term, show } from 'trs';

  const R = rules('+(0, y) -> y\n+(S(x), y) -> S(+(x, y))\nF(x) -> G(x, x)\nA -> B\nG(A, B) -> C');
  test('a step at the root', () => {
    expect(show(rootRewrite(R, term('+(S(0), S(0))')))).toBe('S(+(0, S(0)))');
    expect(show(rootRewrite(R, term('F(+(0, 0))')))).toBe('G(+(0, 0), +(0, 0))');
  });
  test('no rule at the root', () => {
    expect(rootRewrite(R, term('S(+(0, 0))'))).toBe(null);
    expect(rootRewrite(R, term('x'))).toBe(null);
  });
  test('the first matching rule wins', () => {
    const R2 = rules('F(A) -> One\nF(x) -> Two');
    expect(show(rootRewrite(R2, term('F(A)')))).toBe('One');
    expect(show(rootRewrite(R2, term('F(B)')))).toBe('Two');
  });
  test('all one-step reducts, in order', () => {
    expect(allReducts(R, term('+(+(0, 0), +(0, 0))')).map((u) => show(u))).toEqual(['+(0, +(0, 0))', '+(+(0, 0), 0)']);
    expect(allReducts(R, term('G(A, A)')).map((u) => show(u))).toEqual(['G(B, A)', 'G(A, B)']);
    expect(allReducts(R, term('G(A, B)')).map((u) => show(u))).toEqual(['C', 'G(B, B)']);
  });
  test('normal forms have no reducts', () => {
    expect(allReducts(R, term('S(S(0))'))).toEqual([]);
  });
solution: |
  import type { Rule, Term } from 'trs';
  import { match, apply, positions, at, replaceAt } from 'engine';

  export function rootRewrite(rules: readonly Rule[], t: Term): Term | null {
    for (const r of rules) {
      const sigma = match(r.lhs, t);
      if (sigma) return apply(sigma, r.rhs);
    }
    return null;
  }

  export function allReducts(rules: readonly Rule[], t: Term): Term[] {
    const out: Term[] = [];
    for (const p of positions(t)) {
      const sub = at(t, p);
      for (const r of rules) {
        const sigma = match(r.lhs, sub);
        if (sigma) out.push(replaceAt(t, p, apply(sigma, r.rhs)));
      }
    }
    return out;
  }
hints:
  - '`rootRewrite` is a loop over the rules: the first `match(r.lhs, t)` that is not `null` gives `apply(sigma, r.rhs)`.'
  - 'For `allReducts`, loop over `positions(t)`; at each position take the subterm with `at`, try every rule, and put each contractum back with `replaceAt`.'
```

:::key
- A rule $l \to r$ needs a non-variable $l$ and $\mathrm{Var}(r) \subseteq \mathrm{Var}(l)$.
- $s \to t$ replaces an instance $l\sigma$ at some position by $r\sigma$. The relation is closed under substitution and context, and it is the smallest such relation containing the rules.
- A normal form has no redex. A term may have no normal form, one, or several.
:::
