{Wenn ich du wäre, würde ich das nicht machen.} {Wenn ich doch mehr Zeit hätte!} {Könnten Sie mir bitte helfen?}

The **Konjunktiv II** is the mood of things that are not (or not yet) real: wishes, daydreams, hypotheses, regrets, and, in a very German twist, politeness. You have been using it since A1 without being told: {Ich hätte gern einen Kaffee} is Konjunktiv II, and so is {ich möchte}, which is simply the Konjunktiv II of {mögen}: not "I like" but "I would like".

Returners often remember the Konjunktiv II as a forest of strange forms ({gewönne}, {hülfe}, {stürbe}). Good news: modern German uses only a handful of them. For almost everything else there is one all-purpose form, and that is where we start.

## würde + infinitive: the all-purpose form

{Ich würde gern in Wien leben.} I would like to live in Vienna.

"Would" + verb is {würde} + infinitive, with the infinitive at the end, like a modal verb:

| | | | |
| --- | --- | --- | --- |
| {ich würde fahren} | I would go | {wir würden fahren} | we would go |
| {du würdest fahren} | you would go | {ihr würdet fahren} | you (all) would go |
| {er/sie/es würde fahren} | he/she/it would go | {sie/Sie würden fahren} | they/you would go |

{würde} is itself the Konjunktiv II of {werden}: the Präteritum {wurde} plus an umlaut. That umlaut does a lot of work, so watch it:

:::mistake
{wird} (will), {wurde} (became, was … -ed) and {würde} (would) are three different words. {Er wurde Lehrer} means "he became a teacher"; {Er würde Lehrer werden} means "he would become a teacher". If you are typing without umlauts, write {wuerde}, never {wurde}.
:::

```words

der Traum, ¨-e | dream
gewinnen (gewinnt, gewann, hat gewonnen) | to win
im Lotto gewinnen | to win the lottery
die Weltreise, -n | trip round the world

```

## wäre, hätte and the modal verbs

Some verbs are so frequent that they keep a one-word Konjunktiv II, and {würde} with them sounds clumsy. Nobody says {ich würde Zeit haben}; everybody says {ich hätte Zeit}. The recipe: take the Präteritum, add an **umlaut** if the vowel allows it, and an **-e** where there isn't one:

| Infinitive | Präteritum | Konjunktiv II | |
| --- | --- | --- | --- |
| {sein} | {war} | **{wäre}** | would be |
| {haben} | {hatte} | **{hätte}** | would have |
| {können} | {konnte} | **{könnte}** | could |
| {müssen} | {musste} | **{müsste}** | would have to |
| {dürfen} | {durfte} | **{dürfte}** | would be allowed to |
| {sollen} | {sollte} | **{sollte}** | should |
| {wollen} | {wollte} | **{wollte}** | would want to |
| {mögen} | {mochte} | **{möchte}** | would like |
| {wissen} | {wusste} | **{wüsste}** | would know |
| {kommen} | {kam} | **{käme}** | would come |
| {gehen} | {ging} | **{ginge}** | would go |
| {geben} | {gab} | **{gäbe}** | would give; {es gäbe} there would be |

{sollte} and {wollte} have no umlaut, so they look exactly like the Präteritum; the context tells you which is meant. The endings are those of the Präteritum: {ich wäre}, {du wärst}, {er wäre}, {wir wären}, {ihr wärt}, {sie wären}.

:::key
In everyday German, use the one-word form for **sein, haben, the modal verbs and wissen**, and often for {käme}, {ginge}, {gäbe}. For **every other verb**, use {würde} + infinitive. For a regular verb you have no choice anyway: its Konjunktiv II looks exactly like the Präteritum ({ich spielte}), so {ich würde spielen} is the only way to make it clear.
:::

:::note
You will also hear {bräuchte} (from {brauchen}) and {täte} (from {tun}), and in literature older forms such as {ich führe}, {ich liefe}, {ich hülfe}. Recognise them; don't feel you have to use them.
:::

## Polite requests: Könnten Sie …?

German politeness lives in the verb. The Konjunktiv II softens a request the way English adds "could you possibly …":

| | |
| --- | --- |
| {Geben Sie mir das Salz.} | an order; fine between family, abrupt elsewhere |
| {Können Sie mir das Salz geben?} | neutral |
| {Könnten Sie mir bitte das Salz geben?} | polite |
| {Würden Sie mir vielleicht das Salz geben?} | very polite |

The most useful forms: {Könnten Sie …?}, {Würden Sie …?}, {Hätten Sie …?} (Do you have …?), {Dürfte ich …?} (May I …?), {Wüssten Sie …?} (Would you know …?), {Wäre das möglich?}, and of course {Ich hätte gern …} and {Ich würde gern …}.

:::mistake
{Ich will …} in a shop or hotel sounds like a toddler's demand. {Ich möchte …} or {Ich hätte gern …} is what adults say. Likewise {Haben Sie …?} is fine, but {Hätten Sie …?} sounds noticeably friendlier.
:::

```words

leihen (leiht, lieh, hat geliehen) | to lend; to borrow
wecken | to wake (someone) up
der Gefallen, - | favour
möglich | possible
```

## Wishes and advice

**Wishes** for things that aren't so take the Konjunktiv II, usually with {doch} and/or {nur}:

- {Wenn ich doch mehr Zeit hätte!} If only I had more time!
- {Wenn er nur anrufen würde!} If only he would ring!
- {Hätte ich doch ein Auto!} If only I had a car! (verb first, no {wenn})
- {Ich wünschte, ich wäre am Meer.} I wish I were by the sea.

**Advice** comes in several strengths:

| | |
| --- | --- |
| {Du solltest mehr schlafen.} | You should sleep more. |
| {Ich würde mehr schlafen.} | I'd sleep more (if I were you). |
| {An deiner Stelle würde ich mehr schlafen.} | In your place, I'd sleep more. |
| {Wenn ich du wäre, würde ich mehr schlafen.} | If I were you, I'd sleep more. |
| {Es wäre besser, wenn du mehr schlafen würdest.} | It would be better if you slept more. |

## If … then: unreal conditions

Compare:

| | |
| --- | --- |
| {Wenn ich Zeit habe, komme ich mit.} | If I have time, I'll come. (I may well have time.) |
| {Wenn ich Zeit hätte, würde ich mitkommen.} | If I had time, I'd come. (I don't have time.) |

The first is a real condition and uses the indicative. The second is unreal, contrary to fact, and uses the Konjunktiv II in **both** clauses. Word order is the usual one: a {wenn} clause first sends the verb of the main clause to the front ({würde ich}), and you can also turn it round: {Ich würde mitkommen, wenn ich Zeit hätte.}

In writing you will also meet conditions without {wenn}, with the verb first: {Hätte ich Zeit, würde ich mitkommen.}

:::note
English never puts "would" in the if-clause ("if I would have time" is wrong). German is more relaxed: {wenn du mich fragen würdest} is perfectly normal in speech. With sein, haben, the modals and wissen, though, always use the one-word form: {wenn ich Zeit hätte}, never {wenn ich Zeit haben würde}.
:::

::konjunktiv-lab

## The past: hätte gemacht, wäre gegangen

{Wenn ich das gewusst hätte, wäre ich zu Hause geblieben.} If I had known that, I would have stayed at home.

For things that didn't happen in the past, use **{hätte}** or **{wäre}** + participle. The choice between them is the same as in the Perfekt: {ich habe gewusst} → {ich hätte gewusst}; {ich bin geblieben} → {ich wäre geblieben}.

| | Konjunktiv II |
| --- | --- |
| present | {Wenn ich Zeit hätte, würde ich kommen.} |
| past | {Wenn ich Zeit gehabt hätte, wäre ich gekommen.} |

This is also the tense of regret: {Hätte ich doch nur mehr gelernt!} If only I had studied more! And English "would have done" never needs {würde} in German: {ich hätte gemacht}, {ich wäre gegangen}.

## Should have, could have, as if

**"Could have", "should have", "would have had to"** use {hätte} + infinitive + modal infinitive, a so-called double infinitive. There is no participle:

- {Du hättest mich anrufen können.} You could have rung me.
- {Ich hätte das nicht sagen sollen.} I shouldn't have said that.
- {Wir hätten früher losfahren müssen.} We would have had to leave earlier.

Compare {Du solltest mehr schlafen} (you should, now) with {Du hättest mehr schlafen sollen} (you should have, but didn't).

:::grammar[The double infinitive in a subordinate clause]
In a subordinate clause, {hätte} does not go to the very end but **before** the two infinitives: {Es tut mir leid, dass ich dich nicht hätte anrufen können.} This is one of the few exceptions to the verb-last rule. You will mostly meet it in writing; in speech people often rephrase.
:::

**{als ob}**, "as if", takes the Konjunktiv II, because what follows isn't true:

- {Er tut so, als ob er alles wüsste.} He acts as if he knew everything.
- {Sie sieht aus, als ob sie nicht geschlafen hätte.} She looks as if she hadn't slept.

With {als} alone, the verb comes straight after it: {Er tut so, als wüsste er alles.} In casual speech you will also hear the indicative ({als ob er alles weiß}), but the Konjunktiv II is the standard.

```words
tun (tut, tat, hat getan) | to do
so tun, als ob | to act as if, to pretend
```
