# Project notes for Claude

"Auf Deutsch", an interactive German course (A1 to B2) for English speakers, beginners and
returners, in `courses/german/` of the Interactive Courses monorepo. Read README.md and
docs/AUTHORING.md first; `content/lessons/04-familie.md` is the model lesson.

- SvelteKit 2 + Svelte 5 (runes) static site, TypeScript. Output in `dist/`. Base path: BASE_PATH,
  or COURSES_BASE_PATH + /german from the monorepo build.
- British English explanations; German is current standard German (Duden).
- Lessons: `content/lessons/*.md`, outline in `content/outline.ts`. German in prose is written in
  {braces}. Dictionary: `content/data/` (generated by `npm run lexicon` from the word lists and
  Wiktionary data in `build/wiktionary-de.jsonl.gz`, see scripts/slim-wiktionary.py).
- Core libraries in `src/lib`: `de/` (notation, tokenising, lexicon, verbs, answer marking,
  gender rules), `audio/` (speech playback, microphone), `srs/` (FSRS deck), `state/`, `tutor/`.
- Widgets: `src/lib/widgets/` (German data in `src/lib/widgets/data/`); gallery at /dev/widgets/
  in `npm run dev`.
- Every module with logic has vitest tests. Before finishing: `npm test`, `npm run check`, and
  `npm run build` if pages or components changed.
